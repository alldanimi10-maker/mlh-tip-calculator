# mlh-tip-calculator

Simple tip calculator mini app for MLH Global Hack Week: Builders Week Challenge 1. Enter a bill amount and tip percentage to get the tip amount and total price, updated live as you type.

## Live demo

https://alldanimi10-maker.github.io/mlh-tip-calculator/

## How to run

Open `index.html` in any browser, or visit the live demo above. No build step or dependencies are needed.

## Features

- Bill amount input (non-negative numbers only)
- Tip percentage slider and number input (0-50% slider, up to 100% by number)
- Live tip amount and total price calculation
- Reset button

## Note

This app was built for Challenge 1 after Cursor's web cloud agents turned out to require a Premium account on the free plan, so the single-file app was created directly in this repository instead. No code in this repo was generated by Cursor.
